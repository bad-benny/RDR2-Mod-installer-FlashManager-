Red Dead Redemption 2

FlashManager

Prep the story-mode folder, then add or remove mods.

Story mode only. Script Hook closes the game if you enter Red Dead Online, and playing Online with these files installed can cost you the account. Take the mod files out before you play Online.

Game folder

FlashManager looks for Steam, Epic, and Rockstar. Paste the folder that contains RDR2.exe and press Enter, or click Browse.

Lenny's site asks the browser to prove it is a person. Download the top zip, the one named lml_rdr_beta. FlashManager will install it when the file finishes landing in Downloads.

Essentials

Prep downloads the current Script Hook, ASI loader, Lenny's Mod Loader, and the .NET script plugin from each author's own site.

Epic and the Rockstar launcher sometimes ignore dinput8.dll. If the game starts and mods do nothing, switch the loader to version.dll and run Prep again.

How to use

  1. Double-click Start FlashManager.bat and leave the black window open. Closing the browser does not stop it.
  2. Check the game folder above. If yours is missing, paste the folder that contains RDR2.exe and press Enter, or click Browse. A Rockstar install under Program Files needs Run as administrator before Prep or a drop can create folders.
  3. Click Prep. It downloads the current Script Hook, ASI loader, .NET script plugin, and Lenny's Mod Loader. Close the game first. Native Trainer stays off unless you tick it.
  4. If Lenny's site opens, download the zip whose name starts with lml_rdr_beta. FlashManager installs it when the file finishes landing in Downloads. You can also drop that zip on the Modify tab.
  5. Open Modify to add or remove mods and story saves. Play story mode from Steam, Epic, or the Rockstar Launcher. Do not take these files into Red Dead Online. If Epic or Rockstar starts the game and mods never load, switch the ASI loader to version.dll and run Prep again.

      Popular mods

      Story mode. Get downloads the latest file from that author's own GitHub and puts it in the game folder. Run Prep first so Script Hook is there. Remove takes that mod back out. These are not for Red Dead Online.

      Story saves

      Drop a file named SRDR30000 through SRDR30015, or a zip of those files, on the pad above. SRDR30015 is the autosave. SRDR30000 is manual slot 1, SRDR30001 is slot 2, and so on. The matching .bak file can come along.

      Looking for a Rockstar profile…

      The file you replace is copied to _flashmanager_save_backup, next to the Profiles folder. If the game puts the old save back, Rockstar cloud sync is overwriting it. Turn cloud sync off for Red Dead Redemption 2 and drop the save again.

      How to use

      1. Drop a mod on the pad. A folder with install.xml goes in lml. An .asi file sits next to RDR2.exe. A C# script goes in scripts. Loose textures without install.xml, OpenIV packages, and programs are set aside under Needs a look. Nothing you drop is launched.
      2. Under Popular mods, click Get on the ones you want. FlashManager downloads that author's latest release and installs it. Update fetches the latest release again. Remove takes it back out.
      3. Under In the game, click Remove, then Remove now, to take a dropped mod out. The previous copy is in Backups.
      4. To add a story save, pick your profile under Story saves, then drop the SRDR file or its zip on the pad. Launch story mode once first if no profile is listed.
